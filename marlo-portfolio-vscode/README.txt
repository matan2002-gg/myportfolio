MARLO BENISANO PORTFOLIO — VS CODE SETUP

FILES
- index.html: page structure and portfolio content
- style.css: responsive layout and monochrome, developer-style visual design
- script.js: Experience/Education tabs, scroll-triggered photo reveals, and reading progress
- images/: put your own images here

STEP BY STEP
1. Extract marlo-portfolio-vscode.zip to a folder on your computer.
2. Open Visual Studio Code. Select File > Open Folder and choose the extracted marlo-portfolio-vscode folder.
3. Add your portrait as images/profile.jpg.
4. Add two personal photos as images/photo-journey.jpg and images/photo-work.jpg. They appear between the portfolio sections and animate into view as you scroll.
5. Open index.html. To preview, right-click index.html and choose Open with Live Server if you have the Live Server extension installed. Otherwise, double-click index.html in File Explorer to open it in your browser.
6. To change text, edit index.html. To change colors, spacing, and responsive layout, edit style.css. The Experience/Education tabs, photo reveals, and reading progress indicator are handled in script.js.
7. Save files with Ctrl+S and refresh the browser.

IMPORTANT
- Add your portrait as images/profile.jpg and the two scroll photos listed above. Designed placeholders display until the images are added.
- Update the project descriptions and contact email in index.html to match your current work before publishing.
